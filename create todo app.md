# Task: create a TODO app

Build a small TODO web app you can open in a browser. This is the whole task — when the list
survives a page reload, you are done.

## What it has to do

1. Add a task by typing it and pressing Enter.
2. Tick a task off, and untick it.
3. Delete a task.
4. Still be there after a page refresh.

## Where to start

Don't plan the whole thing. Ask the **guidance agent** on this project's home page — it will give
you a file layout, a build order, and the first file written out in full.

If you get stuck, or the guidance you get doesn't fit what you're seeing, open a ticket with the
**Help desk** button. Someone from the app-build desk picks those up.
