# Task: build something and see it in a browser

Pick an app you actually want — a habit tracker, a recipe box, a tip splitter, a
pomodoro timer, a landing page for a band that does not exist. Anything. The point
is not the idea; the point is that in a few minutes you are looking at a real page
in a real browser instead of reading about one.

## What "done" looks like

A single `.html` file you can double-click. No install, no build step, no
`node_modules`. It should look like someone designed it — not like a form from 1998.

## Where to start

Don't plan it. **Agent Smith** is on this project's home page — click him, tell him
what you want to build, and he will produce the demo page for you to open. Then tell
him what to change.

If you get stuck, or what he builds isn't what you meant, open a ticket with the
**Help desk** button. Someone from the app-build desk picks those up.
